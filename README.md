# Mouad Shop - متجر إلكتروني متكامل

متجر إلكتروني احترافي يوفر واجهة متقدمة لعرض وبيع المنتجات مع لوحة إدارة متكاملة.

## ✨ الميزات الرئيسية

### الواجهة الرئيسية (index.html)
- 🎨 تصميم حديث وجذاب مع تدرج لوني احترافي
- 📱 واجهة استجابة تدعم جميع الأجهزة (هواتف، أجهزة لوحية، حواسيب)
- 🛍️ عرض ديناميكي للمنتجات مع الأسعار بالدينار
- 📞 أيقونات وروابط مباشرة للتواصل عبر الواتساب والفيسبوك
- ⚡ أداء سريع وتحميل فوري

### لوحة الإدارة (admin.html)
- ➕ إضافة منتجات جديدة بسهولة
- ✏️ تعديل بيانات المنتجات (الاسم، السعر، الوصف)
- 🖼️ رفع صور للمنتجات
- 📊 عرض إحصائيات المتجر
- 🔍 البحث والفلترة حسب الفئة
- 📥 تصدير البيانات بصيغة JSON
- 🗑️ حذف منتجات وإدارة المخزون

## 📁 هيكل المشروع

## 🚀 البدء السريع

### خطوات التشغيل

1. **فتح المتجر الرئيسي:**
   - افتح ملف `index.html` في متصفح الويب
   - سيتم تحميل المتجر مع منتجات افتراضية

2. **الوصول إلى لوحة الإدارة:**
   - انقر على "لوحة الإدارة" في القائمة العلوية
   - أو افتح ملف `admin.html` مباشرة

3. **إضافة منتج جديد:**
   - املأ نموذج "إضافة منتج جديد" في لوحة الإدارة
   - أدخل: الاسم، السعر، الفئة، الرمز (Emoji)، الوصف
   - يمكنك رفع صورة للمنتج
   - انقر "إضافة المنتج"

4. **إدارة المنتجات:**
   - اعرض جميع المنتجات في الجدول
   - ابحث عن منتج محدد
   - فلّر حسب الفئة
   - عدّل أي منتج
   - احذف المنتجات غير المرغوبة

## 💾 التخزين

- لا توجد قاعدة بيانات خارجية مطلوبة

## 🎓 نصائح الاستخدام

1. **الرموز (Emoji):**
   - استخدم رموز تعبيرية لتمثيل المنتجات
   - مثال: 📚 للكتب، 💻 للأجهزة، 🎧 للسماعات

2. **الأسعار:**
   - أدخل الأسعار بدون علامة العملة
   - سيتم عرضها تلقائيًا مع "دينار"

3. **الصور:**
   - يمكنك رفع صور حقيقية للمنتجات
   - أو استخدام الرموز التعبيرية كبديل

4. **الأوصاف:**
   - اكتب وصفًا تفصيليًا للمنتج
   - ركز على الميزات المهمة

## 🐛 استكشاف الأخطاء

- **المنتجات لا تظهر:** تأكد من تفعيل localStorage في متصفحك
- **الصور لا تحفظ:** جرب تحديث الصفحة أو استخدم رموز Emoji بدلاً منها
- **البيانات مفقودة:** تحقق من بيانات localStorage في أدوات المطور (F12)
